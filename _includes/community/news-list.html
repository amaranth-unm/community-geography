{% comment %} News listing include. Params: include.year - restrict to a single year (e.g. "2024") include.featured - homepage widget: hand-picked stories in featured_order include.full - render full article body instead of a teaser excerpt Stories without a published_date give a published_year instead. Jekyll's `sort`/`where`/`group_by` filters resolve document properties through a Liquid-drop property cache (Jekyll::Filters#item_property) that has proven unreliable in production - it has caused both scrambled chronological order and broken year grouping. So, apart from the small hand-curated `featured` list below, everything here is ordered and grouped with plain Liquid (string ops, bracket indexing, and `sort`/`push` with no property argument), none of which touch that cache. {% endcomment %} {% if include.featured %} {% assign stories = site.news | where_exp: 'story', 'story.featured_order' | sort: 'featured_order' %} {% else %} {% comment %} Build a "date_index" sort key per story (zero-padded index as a tiebreaker/pointer back into the original array), sort those keys as plain strings (newest first), then rebuild `stories` in that order. {% endcomment %} {% assign all_stories = site.news %} {% assign keys = "" %} {% for story in all_stories %} {% assign story_date = story.published_date %} {% unless story_date %}{% assign story_date = story.published_year | append: "-00-00" %}{% endunless %} {% assign idx = forloop.index0 | append: "" %} {% case idx.size %} {% when 1 %}{% assign idx = "00" | append: idx %} {% when 2 %}{% assign idx = "0" | append: idx %} {% endcase %} {% assign key = story_date | append: "_" | append: idx %} {% if keys == "" %}{% assign keys = key %}{% else %}{% assign keys = keys | append: "," | append: key %}{% endif %} {% endfor %} {% assign sorted_keys = keys | split: "," | sort | reverse %} {% assign stories = "" | split: "," %} {% for key in sorted_keys %} {% assign idx = key | slice: -3, 3 | plus: 0 %} {% assign stories = stories | push: all_stories[idx] %} {% endfor %} {% endif %} {% comment %} A single already-filtered year, or a hand-picked featured list, reads fine as one flat chronological list.
