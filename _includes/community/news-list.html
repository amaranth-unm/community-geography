Params: include.year - restrict to a single year (e.g. "2024") include.limit - show only this many of the newest stories, as one flat list (the homepage's Recent News) include.full - render full article body instead of a teaser excerpt The News page uses none of these: it shows every story, grouped by year, under a row of year buttons. The buttons come from the stories' dates, so a new year gets one when its first story is added. With JavaScript (assets/js/news-year-filter.js) a button shows only that year, and /news/#year-2024 opens the page already filtered. Without JavaScript the buttons jump to the year's heading and every year stays on the page. Stories without a published_date give a published_year instead. Dates and years work with or without quote marks: the list is put in date order by helpers/sort-by-date.html, and each story's year is compared as text (`append: ""`), because a year written without quote marks is a number and would never match the text "2026". {% endcomment %} {% include helpers/sort-by-date.html items=site.news field="published_date" fallback="published_year" order="newest" %} {% assign stories = sorted_by_date %} {% comment %} A single already-filtered year, or the few newest stories, reads fine as one flat chronological list.
