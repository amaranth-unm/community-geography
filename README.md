# Community Geography

The website of the R.H. Mallory Center for Community Geography at the University of New Mexico, published at <https://amaranth.unm.edu/community-geography/>.

It is a Jekyll site built with the [Xanthan](https://github.com/xanthan-web/xanthan) framework and UNM branding. GitHub Pages builds and publishes the site from the `main` branch every time it changes. There are no custom plugins or build workflows.
