# Community Geography

The website of the R.H. Mallory Center for Community Geography at the University of New Mexico, published at <https://amaranth.unm.edu/community-geography/>.

It is a Jekyll site built with the [Xanthan](https://github.com/xanthan-web/xanthan) framework and UNM branding. Changes merged into `main` are built, checked, and published by GitHub Actions.

- **Editing the site:** [HOW-TO-EDIT-THIS-WEBSITE.md](HOW-TO-EDIT-THIS-WEBSITE.md)
- **Scripts, checks, and workflows:** [scripts/README.md](scripts/README.md)
